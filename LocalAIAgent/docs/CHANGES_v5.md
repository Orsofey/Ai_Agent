# Версия 5.0: анализ и изменения

## Что было

**Старая версия (корень репозитория `orsofey/ai_agent`)**: Flask + Web Speech API браузера,
распознавание только в Chrome/Edge и только при открытом окне, команды на регулярных выражениях,
pyautogui для клавиатуры, отдельный Flutter-клиент.

**Версия 4.0 (архив Ai_Agent.zip)**: переработанный каркас (SQLite, код подключения, pywebview,
автозапуск, Playwright-браузер агента, Piper TTS, faster-whisper small на CPU).

Найденные проблемы 4.0:

1. `assistant_commands.handle()` в конце всегда возвращал «Не понял команду». Из-за этого
   `process_command` никогда не доходил до разговорных ответов и основного разбора команд:
   «Открой калькулятор», «Привет», «Который час» — всё отвечало «Не понял команду».
   Тесты архива это показывали: 14 из 68 падали.
2. «Открой Spotify» / «Открой Яндекс Музыку» открывали страницу загрузки вместо сервиса,
   вызывался несуществующий метод браузера `find_and_play_video`.
3. Распознавание медленное: запись в браузере → webm → сервер → Whisper small, beam 5, CPU
   (по отчёту архива 4–7 с на фразу) плюс 1,2 с ожидания тишины.
4. Нет ответов на произвольные вопросы: только шаблонные фразы.
5. Голос работал только при открытом окне; ввод текста разрешён лишь в 7 редакторах.
6. Кеш озвучки использовал `hash()`, который меняется при каждом запуске Python, поэтому кеш не работал.

## Что сделано

| Требование | Решение |
|---|---|
| 1. Скорость распознавания RU/EN | onnx-asr + ONNX Runtime: NVIDIA Parakeet TDT 0.6B v3 (RU+EN, автоопределение языка) и Sber GigaAM v3 (RU); int8; прогрев модели при запуске; нативный захват микрофона 16 кГц кадрами по 32 мс; Silero VAD режет фразу через 0,6 с тишины (настраивается от 0,25 с) и обрезает хвост тишины |
| 2. Скорость ответа | мгновенные ответы из первоисточников (ЦБ РФ, Open-Meteo, CoinGecko, калькулятор) без ИИ; потоковый ответ ИИ с озвучкой по предложениям (Piper синтезирует следующую фразу, пока звучит текущая); `effort: low` для голосовых ответов; кеш данных |
| 3. Точность распознавания | GigaAM v3 / Parakeet v3 вместо Whisper small; нормализация громкости; фильтр «угу/ээ»; нечёткое распознавание имени («Андрэй», «Andrey», «Андрею»); доп. варианты имени в настройках; числа словами → цифры для расчётов |
| 4. Любые вопросы | Claude (по умолчанию Opus 5, можно Haiku 4.5 для скорости) + встроенный веб-поиск Anthropic + собственные инструменты (курсы ЦБ, погода, криптовалюты); память последних 6 реплик; OpenAI-совместимый режим (Ollama, LM Studio, OpenRouter) с поиском DuckDuckGo |
| 5. Настройки в отдельном окне | `/settings` открывается отдельным окном pywebview (или вкладкой в браузере); 9 разделов, автосохранение, синхронизация с главным окном через BroadcastChannel и SSE |
| 6. Пять тем | Аврора, Киберпанк, Сакура, Бездна, Люкс (+ классические тёмная/светлая) с живым анимированным фоном и превью |
| 7. Работа во всех приложениях | фоновое прослушивание с именем «Андрей» (настраивается), трей, глобальная горячая клавиша; ввод текста через SendInput Unicode в любое окно (или через буфер обмена для длинного текста); запоминание последнего окна пользователя; мессенджеры (Telegram, WhatsApp, Discord, Slack, Viber); ИИ-действия с выделенным текстом; диктовка; клавиши, окна, звук, медиа |

Дополнительно исправлено: маршрутизация сервисов, кеш озвучки (sha1 вместо `hash()`),
защита `/tts_audio/` от обхода пути, автозапуск стартует свёрнутым в трей.

## Ограничения

- Модели скачиваются с Hugging Face один раз (SETUP_WINDOWS.bat или кнопка в настройках).
  В среде, где собиралась эта версия, Hugging Face был недоступен, поэтому реальные
  замеры скорости на моделях не проводились. Цифры взяты из бенчмарков onnx-asr; фактическое
  время последней фразы видно в интерфейсе.
- Управление другими приложениями работает на Windows. Окна, запущенные от имени
  администратора, не принимают ввод от обычного процесса (ограничение Windows UIPI).
- Поиск контакта в мессенджерах имитирует действия пользователя. Если в вашей версии
  мессенджера другие сочетания клавиш, поправьте их в `messenger_profiles.json` в папке данных.
- Для ответов на любые вопросы нужен ключ Anthropic API (или локальный сервер Ollama/LM Studio).
