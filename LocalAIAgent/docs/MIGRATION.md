# Перенос со старой версии

1. Сохраните копию старой папки проекта и `%LOCALAPPDATA%\LocalAIAgent`.
2. Распакуйте новую версию отдельно. Не переносите старый venv.
3. Выполните SETUP_WINDOWS.bat. Закройте запущенные экземпляры агента.
4. Старые users.json, chats.json, settings.json обычно лежат в data старого проекта
   или `%LOCALAPPDATA%\LocalAIAgent\data`.
5. В CMD из новой папки выполните:

```bat
.venv\Scripts\python.exe scripts\import_legacy.py "C:\OS\Ai_Agent\data"
```

Скрипт импортирует локальные аккаунты и их историю/настройки, если целевые профили
пусты. Старые пароли PBKDF2 поддерживаются. Исходные файлы не изменяются.

Гостевые истории не сливаются автоматически. Скрипт напечатает guest_... ключи.
Выберите только нужный вам и выполните:

```bat
.venv\Scripts\python.exe scripts\import_legacy.py "C:\OS\Ai_Agent\data" --guest-key guest_НУЖНЫЙ_КЛЮЧ
```

Он попадёт в гостевой профиль нового окна ПК. Перед импортом сохраняется копия
SQLite `before-legacy-import.sqlite3`. Не запускайте один и тот же импорт многократно:
маркер предотвращает повтор для той же исходной папки и гостевого ключа.

Не удаляйте старые данные, пока не проверите результат. Непустые новые профили
скрипт не заменяет и не объединяет. Форматы чужих версий могут отличаться.
После переноса заново выберите микрофон: его идентификатор в новом WebView2 может измениться.

Android: прежняя подпись и applicationId неизвестны. Новая сборка по умолчанию
может установиться рядом со старой, а не поверх неё. Для обновления нужна исходная
подпись и тот же applicationId; не удаляйте старый keystore.

Старые app.py, main.py, requirements_FIXED, файлы PATCH и дублирующие обработчики
не копировать. Использовать только согласованную структуру этого архива.
