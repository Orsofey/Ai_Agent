# Аккаунты и подписка

Бесплатно работают все команды, ответы на вопросы, голосовое управление, Telegram и YouTube.
По подписке открываются три раздела настроек (в окне настроек на них висит замок):

| Раздел | Что открывается |
|---|---|
| Оформление | 7 тем (без подписки — «Аврора»), анимации |
| Распознавание | выбор движка: Parakeet / GigaAM / Whisper |
| Озвучка | голоса, скорость речи, отключение озвучки |

Тарифы: **100 ₽ за 30 дней** или **500 ₽ навсегда**. Автосписаний нет: месяц продлевается новой оплатой.

## Как это устроено

```
Приложение  ──вход / оплата──▶  server/license_server.py  ──создать платёж / проверить──▶  ЮKassa
     ▲                                   │
     └──── лицензия, подписанная Ed25519 ┘
```

- Пароли хранятся только на сервере (хеш werkzeug), приложение хранит токен входа.
- Сервер выдаёт лицензию `{email, plan, expires}` с подписью Ed25519. Приложение проверяет подпись
  открытым ключом **офлайн**, поэтому подписка работает без интернета, а подделать её без закрытого
  ключа сервера нельзя. Месячная подписка работает ещё 3 дня после окончания, если нет интернета.
- Уведомлениям ЮKassa сервер не доверяет: статус и сумма перепроверяются запросом `GET /v3/payments/{id}`,
  а каждый платёж засчитывается ровно один раз.
- Чек по 54-ФЗ формирует ЮKassa (в платеж передаётся `receipt` с email покупателя).
- Если платёжная страница уже закрыта, а уведомление задержалось, приложение само спрашивает статус
  платежа каждые 5 секунд, а в фоне — раз в 6 часов.

## Запуск сервера

1. Подключите магазин в [ЮKassa](https://yookassa.ru), получите `shopId` и секретный ключ.
   Для чеков включите фискализацию (например, «Чеки от ЮKassa»).
2. На сервере с Python 3.11+:

   ```bash
   cd server
   pip install -r requirements.txt
   python generate_keys.py            # LICENSE_PRIVATE_KEY=... и PUBLIC_KEY
   export LICENSE_PRIVATE_KEY=...      # храните в секрете
   export YOOKASSA_SHOP_ID=... YOOKASSA_SECRET_KEY=...
   export PUBLIC_URL=https://license.example.ru
   export LICENSE_DB=/var/lib/andrey/licenses.db
   waitress-serve --port 8080 --call license_server:create_app
   ```

   Перед сервером поставьте HTTPS (nginx или Caddy).
3. В личном кабинете ЮKassa → Интеграция → HTTP-уведомления укажите
   `https://license.example.ru/yookassa/webhook`, событие `payment.succeeded`.
4. Впишите адрес и открытый ключ в `src/license_config.py` и соберите установщик:

   ```python
   SERVER_URL = 'https://license.example.ru'
   PUBLIC_KEY = '...'
   ```

   Без пересборки то же можно задать файлом `%LOCALAPPDATA%\LocalAIAgent\license.json`
   (`{"server_url": "...", "public_key": "..."}`) или переменными `AGENT_LICENSE_SERVER` и
   `AGENT_LICENSE_PUBLIC_KEY`.

Для отладки без ЮKassa запустите сервер с `LICENSE_TEST_MODE=1`: любая «оплата» проходит сразу.
В продакшене этот режим не включайте.

## API сервера

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/register` `{email, password}` | регистрация, возвращает токен и лицензию |
| POST | `/api/login` | вход (не больше 10 попыток за 10 минут) |
| GET | `/api/me` | аккаунт и свежая лицензия |
| POST | `/api/checkout` `{plan: monthly\|lifetime}` | создать платёж, вернуть ссылку на оплату |
| GET | `/api/payments/{id}` | проверить платёж и применить его |
| POST | `/yookassa/webhook` | уведомления ЮKassa |
