# Вход, регистрация и подписка через Amvera

[Amvera Cloud](https://amvera.ru) — российский хостинг, который сам собирает и запускает сервер
аккаунтов из этого репозитория. Оплата в рублях, есть бесплатный стартовый баланс.

Что даёт сервер: регистрация и вход по email, ваш аккаунт владельца со всеми функциями, промокоды
на подписку навсегда и (по желанию) оплата через ЮKassa.

## 1. Создать проект и загрузить файлы (10 минут)

1. Зарегистрируйтесь на [amvera.ru](https://amvera.ru) → **Создать проект** → тип **Приложение**,
   тариф — самый маленький (серверу хватает).
2. В проекте откройте **Репозиторий** → **Загрузить данные** и загрузите **содержимое папки `server/`**
   (не саму папку и не весь проект):

   | Файл | Зачем |
   |---|---|
   | `amvera.yml` | настройки Amvera: сборка из `Dockerfile`, постоянное хранилище `/data` |
   | `Dockerfile` | как собрать сервер |
   | `requirements.txt` | библиотеки Python |
   | `license_server.py` | сам сервер |
   | `run.py` | запуск |
   | `generate_keys.py` | не обязателен |

   Папку `__pycache__` загружать не нужно (если загрузили — не мешает).
   Файлы должны лежать в корне репозитория Amvera, как на экране «Code» — без вложенной папки `server`.
3. Постоянное хранилище `/data` (аккаунты и ключ подписи) уже указано в `amvera.yml` — вкладка **Data**.

## 2. Переменные (раздел «Переменные» → «Секреты»)

| Имя | Значение | Обязательно |
|---|---|---|
| `OWNER_PASSWORD` | ваш пароль для входа в `orsofey@gmail.com` (от 8 символов) | да |
| `PROMO_CODES` | промокоды через запятую, например `ANDREY-FRIENDS, VIP50:50` (`:50` — не больше 50 активаций) | по желанию |
| `OWNER_EMAILS` | другие email владельца через запятую (по умолчанию `orsofey@gmail.com`) | нет |
| `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` | ключи магазина ЮKassa, когда будете принимать оплату | нет |
| `PUBLIC_URL` | адрес проекта (для возврата после оплаты) | с ЮKassa |

Аккаунт владельца создаётся сервером сам: зарегистрировать `orsofey@gmail.com` кто-то другой не может,
а войти можно только паролем из `OWNER_PASSWORD`. Ему всегда открыто всё.

Промокод вводится в приложении после входа (Настройки → Аккаунт и подписка → «Есть промокод?»)
и даёт подписку навсегда бесплатно. Каждый аккаунт может активировать код один раз.
Промокоды храните в секретах Amvera, а не в репозитории: иначе их увидит любой.

Без ключей ЮKassa работают вход, регистрация и промокоды; кнопки оплаты ответят «Оплата пока не подключена».

## 3. Запустить и проверить

1. **Собрать** → дождитесь зелёного статуса «Запущено».
2. Во вкладке **Домены** скопируйте адрес, например `https://andrey-license-orsofey.amvera.io`.
3. Откройте `…amvera.io/health` в браузере — должно быть `{"success": true, ...}`.

## 4. Подключить приложение

В файле `src/license_config.py` впишите адрес:

```python
SERVER_URL = 'https://andrey-license-orsofey.amvera.io'
PUBLIC_KEY = ''   # можно оставить пустым
```

и пересоберите программу (`BUILD_WINDOWS.bat`). Без пересборки то же можно задать файлом
`%LOCALAPPDATA%\LocalAIAgent\license.json`: `{"server_url": "https://…amvera.io"}`.

Ключ проверки подписки приложение получит от сервера при первом входе (по HTTPS) и запомнит.
Для максимальной защиты впишите его в `PUBLIC_KEY` заранее: откройте `…amvera.io/api/public-key`
и скопируйте значение `public_key`.

## 5. Войти

Настройки → **Аккаунт и подписка** → вкладка «Вход» → `orsofey@gmail.com` и пароль из `OWNER_PASSWORD`.
Замки со всех разделов исчезнут, на карточке будет «Владелец».

## Если что-то не так

- **Сборка красная** — откройте **Логи** → «Лог сборки» и пришлите текст ошибки. Частая причина —
  старые `amvera.yml` и `Dockerfile` (с путями `server/...`): загрузите новые из папки `server/`.
- **После изменения файлов** нажмите **Пересобрать** (иконка ⟳ вверху справа), а в «Реплики» поставьте 1.
- **«Нет связи с сервером подписки»** — проверьте `SERVER_URL` (с `https://`, без `/` в конце) и что
  проект запущен.
- **Нужно сменить пароль владельца** — поменяйте `OWNER_PASSWORD` и перезапустите проект.
- **Не терять аккаунты** — всё хранится в `/data`; не удаляйте хранилище проекта.
