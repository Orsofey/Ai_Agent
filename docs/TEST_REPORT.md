# Отчёт проверки — версия 5.1, 25 сентября 2026

Среда проверки: Linux x86_64, Python 3.11, Chromium (Playwright). Windows-функции
(SendInput, окна, трей, горячая клавиша, WebView2) проверены через подставные объекты:
реальный ввод в приложения Windows в этой среде не выполнялся.

## 1. Автоматические тесты: 287/287 PASS

`python -m unittest discover -s tests -v`, полный вывод в `unit-tests.txt`.

- маршрутизация команд (исправлен баг 4.0: все команды отвечали «Не понял команду»);
- команды для любого приложения: печать текста, «напиши и отправь», мессенджеры, клавиши,
  окна, ИИ-действия с выделенным текстом, диктовка;
- имя-активатор: «Андрей», «Эй, Андрей», ошибки распознавания, имя в конце фразы, без ложных срабатываний;
- голосовой цикл целиком: микрофон → VAD → фраза → распознавание → имя → команда; эхо собственного
  голоса игнорируется, перебивание по имени, горячая клавиша, диктовка;
- источники данных: разбор официального XML Банка России (windows-1251, номинал 100, курс на предыдущую дату),
  MET Norway (коды погоды, сводка по дням в местном времени), Nominatim, Википедия, DuckDuckGo только по включению;
- страница «Лицензии» и отказ от удалённых некоммерческих компонентов;
- мгновенные ответы: курсы ЦБ (включая номинал 100), конвертация с числами словами, кросс-курсы,
  погода с падежами городов, криптовалюты, калькулятор и защита от выполнения кода;
- локальная нейросеть: запуск `llama-server` отдельным процессом, ожидание готовности, потоковый ответ,
  кеш промпта, выбор установленной модели, остановка при смене настроек (с поддельным сервером
  с тем же API); выбор архива llama.cpp для Windows по реальной схеме имён релизов;
  подмешивание результатов поиска; OpenAI-совместимые серверы и фильтр `<think>`;
- API: потоковый чат, идемпотентность, ключи не возвращаются, валидация тем/настроек, SSE, окно настроек,
  защита `/tts_audio/` от обхода пути.

Новое в 5.1 (60 тестов):

- «Пауза»: долгая команда прерывается за доли секунды, ассистент сразу принимает следующую; `/api/cancel`;
  «Андрей, стоп» прерывает без очереди;
- ответы «Да, сэр»: глагол совпадает с командой («включи» → «включаю»), формулировки меняются,
  ошибки — с извинением, обращение и стиль из настроек, обращение в подсказке нейросети;
- «Что открыть, сэр?» → ответ без имени; «запустил Telegram» → «Запустить Telegram, сэр?» → «да»/«нет»;
- YouTube: разбор «открой первое/третье/последнее видео», поиск, перемотка; скрипт выбора видео проверен
  в настоящем Chromium (пропускает шапку, дубли, скрытые и текущее видео);
- Telegram: имена из нескольких слов в любом падеже, псевдонимы «Арсений Крэк = Arseny Crack», поиск
  латиницей, группы, «открой чат с …», «ответь …» в открытый чат;
- подписка: регистрация, вход на втором ПК, оплата месяца и «навсегда», платёж без оплаты, повторные
  уведомления ЮKassa засчитываются один раз, подмена суммы, поддельная лицензия, окончание месяца,
  выход; замки платных настроек (ответ 402);
- macOS: ⌘ вместо Ctrl, сочетания Mac, печать кириллицы через Quartz, `open -a`, вежливое закрытие,
  LaunchAgent, архив llama.cpp для Mac (zip и tar.gz, права на запуск), папка данных;
- iPhone: QR-код подключения, эндпоинт для Siri («Быстрые команды»), теги для экрана «Домой».

## 2. Браузерная проверка интерфейса: PASS

`tests/browser_smoke.py` в Chromium: потоковый ответ в чате, кнопка «Пауза» прерывает ответ,
замки и платёжная карточка без подписки, страница аккаунта, QR-код телефона, после оплаты смена темы
мгновенно применяется в главном окне, автосохранение имени.
Скриншоты всех тем и мобильной вёрстки: `docs/screenshots/`. Ошибок JavaScript нет.

## 3. Не проверено в этой среде

- Скачивание и запуск реальных моделей Parakeet/GigaAM/Silero: Hugging Face был недоступен
  по сетевой политике среды. Вызовы onnx-asr сверены с исходным кодом библиотеки 0.12.
- Настоящие модели Qwen и llama-server (Hugging Face и загрузки GitHub недоступны в среде).
- Реальные запросы к ЦБ, MET Norway, Nominatim, Википедии, CoinGecko: сеть недоступна; проверены
  разбор ответов и логика на фикстурах.
- Ввод в Word/Telegram и работа WebView2 — требуют Windows.
- macOS (Quartz, AppleScript, сборка .dmg) — проверено на заглушках; нужен реальный Mac.
- Настоящие платежи ЮKassa — нужен магазин и ключи; проверено с имитацией API ЮKassa.
- iPhone («На экран Домой», Siri) — нужен реальный iPhone.
