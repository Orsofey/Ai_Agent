# Оплата подписки на расчётный счёт Т-Бизнеса (интернет-эквайринг Т-Банка)

Сервер аккаунтов уже умеет принимать оплату через Т-Банк: создаёт платёж, открывает страницу оплаты
(карта, СБП, T-Pay, SberPay), получает уведомление, перепроверяет статус в банке и включает подписку.
Деньги приходят на ваш расчётный счёт в Т-Бизнесе. Подключается за 1–3 рабочих дня.

## Шаг 1. Что нужно заранее

- Расчётный счёт в **Т-Бизнесе** (ИП или ООО; самозанятым интернет-эквайринг обычно недоступен).
- **Сайт или страница приложения** с: описанием «Андрея», ценами (100 ₽/мес, 500 ₽ навсегда), договором-офертой,
  политикой конфиденциальности, контактами (ИНН, email, телефон). Банк проверяет это при подключении.
  Подойдёт простая страница — например, на Тильде или GitHub Pages.
- **Онлайн-касса** для чеков по 54-ФЗ. Проще всего «Т-Чеки» / облачная касса Т-Банка — подключается там же.

## Шаг 2. Подключить интернет-эквайринг

1. Личный кабинет Т-Бизнеса → **Продукты → Интернет-эквайринг** → «Подключить».
2. Тип подключения — **«Свой сайт» / «API»** (не модуль CMS).
3. Укажите адрес сайта со страницей оплаты, заполните анкету. Дождитесь одобрения.
4. В кабинете эквайринга → **Магазины → ваш магазин → Терминалы** появятся два терминала:
   **тестовый** (`…DEMO`) и **боевой**. У каждого есть **TerminalKey** и **пароль**.

## Шаг 3. Настроить терминал

В настройках терминала (сначала тестового):

| Поле | Значение |
|---|---|
| Уведомления | «По протоколу HTTP» |
| URL для уведомлений | `https://ваш-проект.amvera.io/tbank/webhook` |
| Успешная оплата / ошибка | `https://ваш-проект.amvera.io/paid` |
| Онлайн-касса | подключить, система налогообложения — как у вас (УСН «доходы» — `usn_income`) |

## Шаг 4. Добавить ключи в Amvera

Amvera → проект → **Переменные → Секреты**:

| Имя | Значение |
|---|---|
| `TBANK_TERMINAL_KEY` | TerminalKey (сначала тестового терминала) |
| `TBANK_PASSWORD` | пароль терминала |
| `PUBLIC_URL` | `https://ваш-проект.amvera.io` |
| `TBANK_TAXATION` | система налогообложения: `usn_income` (по умолчанию), `usn_income_outcome`, `osn`, `patent`… |
| `TBANK_TAX` | ставка НДС в чеке: `none` (без НДС, по умолчанию), `vat0`, `vat20`… |

Нажмите «Пересобрать». Если заданы ключи Т-Банка, сервер использует его (ЮKassa — только если ключей Т-Банка нет).

> Пароль терминала — секрет. Его не нужно присылать мне или кому-либо: достаточно положить в «Секреты» Amvera.

## Шаг 5. Проверить на тестовом терминале

1. В приложении: Настройки → Аккаунт → войдите → «Оплатить 100 ₽».
2. На странице Т-Банка используйте тестовую карту из раздела «Тестирование» кабинета эквайринга.
3. Через несколько секунд подписка включится в приложении. Банк требует пройти его тестовые сценарии
   (успешная оплата, отказ) — отметьте их в кабинете.

## Шаг 6. Включить боевой режим

Замените в секретах Amvera `TBANK_TERMINAL_KEY` и `TBANK_PASSWORD` на боевые, повторите настройку
уведомлений для боевого терминала и пересоберите. Всё — платежи идут на расчётный счёт.

## Как это устроено

- `Init` — создание платежа (сумма в копейках, чек 54-ФЗ с email покупателя), в ответ — ссылка на оплату.
- Уведомление на `/tbank/webhook` проверяется по подписи (SHA-256 от параметров и пароля терминала),
  затем статус **всё равно** перепроверяется запросом `GetState` — поддельное уведомление ничего не даст.
- Сверяется сумма; каждый платёж засчитывается один раз; ответ банку — `OK`.
