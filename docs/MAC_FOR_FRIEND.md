# Как отправить «Андрея» другу на Mac, если у вас только Windows

Mac-приложение нельзя собрать на Windows, но его бесплатно соберут серверы GitHub на настоящих Mac.
От вас — несколько кликов в браузере, от друга — скачать файл и перетащить значок.

## Часть 1. Вы: собрать приложение (один раз, ~40 минут ожидания)

1. Отправьте последние изменения на GitHub (у вас это уже сделано, если вы работаете с этой веткой).
2. Откройте репозиторий на github.com → справа **Releases** → **Draft a new release**
   (или **Create a new release**).
3. Заполните:
   - **Choose a tag** → впишите новое имя, например `v5.2` → **Create new tag**;
   - **Target** → выберите ветку с программой (`claude/gallant-volta-tlj9p4` или `main`);
   - название — например «Андрей для Mac».
4. Нажмите **Publish release**.
5. Откройте вкладку **Actions** — там идёт «Build macOS app». Когда появится зелёная галочка
   (через 30–40 минут), вернитесь в **Releases**: в вашем релизе появятся файлы
   - `Andrey-AppleSilicon.dmg` — для Mac на M1, M2, M3, M4 (почти все Mac с 2021 года);
   - `Andrey-Intel.dmg` — для старых Mac на Intel.

   Какой нужен другу: меню  → «Об этом Mac» → строка «Чип» (Apple M… — первый) или «Процессор» (Intel — второй).
6. Отправьте другу ссылку на нужный файл (правый клик по файлу в релизе → «Копировать ссылку»).
   Если репозиторий приватный, скачайте файл сами и отправьте через облако (Яндекс Диск, Google Drive).

Размер ≈ 1,3 ГБ: внутри уже есть распознавание речи, голоса и движок нейросети. Саму нейросеть
(2,5 ГБ) приложение скачает при первом запуске — прогресс виден в окне, ничего нажимать не нужно.
Больше GitHub не разрешает класть в релиз одним файлом (до 2 ГБ).

> Минуты сборки: для публичного репозитория бесплатно. Для приватного бесплатных минут macOS
> хватает примерно на две сборки в месяц.

## Часть 2. Друг: установить (2 минуты)

1. Открыть `Andrey-….dmg` двойным щелчком.
2. Перетащить значок **Андрей** на папку **Программы** в том же окне.
3. Открыть «Программы» → **Андрей**.
4. **Только в первый раз** macOS скажет, что не может проверить разработчика (у сборки нет платной
   подписи Apple). Нужно:
   - macOS 15 и новее: нажать «Готово» → **Системные настройки → Конфиденциальность и безопасность** →
     внизу «Андрей заблокирован…» → **Всё равно открыть** → ввести пароль;
   - macOS 14 и старше: правый клик по «Андрей» → **Открыть** → **Открыть**.
5. Разрешить, когда спросит: **Микрофон** и **Универсальный доступ** (чтобы печатать в другие программы).
   Для горячей клавиши ⌃⌥Пробел — ещё «Мониторинг ввода» (Системные настройки → Конфиденциальность).

Дальше приложение открывается обычным щелчком по значку. Говорить: «Андрей, …».

## Чтобы у друга не было даже шага 4

Apple пропускает без предупреждений только приложения, подписанные сертификатом Apple Developer
(99 $ в год, developer.apple.com). Если оформите — сборка подпишет и заверит приложение сама:

1. В Xcode или на developer.apple.com создайте сертификат **Developer ID Application**, экспортируйте
   его в файл `.p12` с паролем. На сайте appleid.apple.com создайте «пароль для приложения».
2. GitHub → репозиторий → **Settings → Secrets and variables → Actions → New repository secret**, добавьте:

   | Имя | Значение |
   |---|---|
   | `MAC_CERT_P12` | содержимое `.p12` в base64 (в PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("cert.p12"))`) |
   | `MAC_CERT_PASSWORD` | пароль от `.p12` |
   | `MAC_SIGN_IDENTITY` | `Developer ID Application: Ваше Имя (TEAMID)` |
   | `APPLE_ID` | ваш Apple ID (email) |
   | `APPLE_TEAM_ID` | Team ID из developer.apple.com |
   | `APPLE_APP_PASSWORD` | пароль для приложения |

3. Сделайте новый релиз, как в части 1. Теперь `.dmg` открывается у друга просто двойным щелчком.

## Если что-то пошло не так

- **Сборка в Actions красная** — откройте её, нажмите на упавший шаг и пришлите текст ошибки.
  Сборка для Intel может падать, если GitHub убрал Intel-машины; на сборку для Apple Silicon это не влияет.
- **Не открывается даже через «Всё равно открыть»** — в Терминале у друга:
  `xattr -dr com.apple.quarantine /Applications/Андрей.app`, затем открыть снова.
- **Нет звука или не слышит** — Системные настройки → Конфиденциальность → Микрофон → включить «Андрей».
- **Не печатает в другие программы** — «Универсальный доступ» → включить «Андрей» (если был — выключить и включить).
- **Платные разделы с замком** — пока не запущен сервер подписки (docs/SUBSCRIPTION.md), они закрыты
  у всех. Команды и ответы работают бесплатно.
