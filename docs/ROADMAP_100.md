# 100 идей для развития Local AI Agent

Это предложения, а не заявление о наличии функций в текущей версии.
Приоритет: сначала надёжность и безопасность, затем интеллектуальные сценарии.

2. Потоковое распознавание без пауз между фразами.
3. Выбор small/medium/large с тестом скорости конкретного ПК.
4. Автонастройка числа CPU-потоков по нагрузке.
5. Ускорение на Intel/AMD через совместимый backend, если доступен.
6. Калибровка громкости и шумового порога под комнату.
7. Индикатор уровня сигнала и предупреждение о клиппинге.
8. Кнопка «Проверить микрофон» с воспроизведением записи.
9. Пользовательский словарь имён приложений, контактов и терминов.
10. Сравнение альтернатив транскрипции перед опасной командой.

12. Автоматическое переключение на гарнитуру при подключении.
13. Эхоподавление с учётом звука самого агента.
14. Локальная озвучка ответов Piper или Windows SAPI.
15. Несколько голосов и настройка скорости озвучки.
