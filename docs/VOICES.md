# Голоса Джарвиса и Пятницы

В Настройках → Озвучка выберите «Джарвис» или «Пятница». Поддерживаются готовые
записи и отдельная модель Piper для произвольного текста.

## Джарвис: записи русского дубляжа

В `models/voice_packs/jarvis` добавлены 58 коротких WAV из предоставленного
пользователем архива. Музыкальные заставки и длинный рассказ исключены. Формат:
PCM 16 бит, моно, 22050 Гц. Дополнительное изменение тона не применяется.

`manifest.json` содержит расшифровку каждой реплики и соответствующий WAV.
Совпадение проверяется целиком, без учёта регистра и пунктуации. Короткие ответы
«Готово», «Сделано», «Выполнено» используют «Запрос выполнен, сэр»; «Хорошо» —
«Как пожелаете». Динамический ответ «Открыл Telegram» не заменяется общей репликой.
Готовые реплики работают без Piper. Для остальных фраз используется выбранный
синтезатор. **Записи не являются моделью и не читают новые предложения голосом актёра.**

## Пятница

В указанном пользователем проекте `Maoghostinq/FridayYO` используется системный
синтезатор Windows; записей русского кинодубляжа и модели этого голоса там нет.
В эту версию такой голос не добавлен. До получения записей или отдельной модели
продолжает использоваться Piper «Ирина» с эффектом.

## Отдельная модель персонажа для всех фраз

В папку данных приложения `models/voices` поместите пару файлов:

| Выбор | Модель | Конфигурация |
| --- | --- | --- |
| Джарвис | `jarvis.onnx` | `jarvis.onnx.json` |
| Пятница | `friday.onnx` | `friday.onnx.json` |

Это должны быть готовые совместимые модели Piper, а не переименованные аудиозаписи.
Они автоматически подхватываются персонажем и читают новый русский текст без
эффектов, меняющих исходный голос. Загрузить пару можно существующей кнопкой
«Загрузить файлы голоса», предварительно дав файлам названия из таблицы.
Сами модели в этом изменении не добавлены. При сборке содержимое проектной папки
`models/voices` включается в установщик автоматически, если эта папка существует.

Пакет готовых реплик Пятницы можно положить в `models/voice_packs/friday`.
Формат `manifest.json`:

```json
{"version": 1, "phrases": [
  {"text": "Да.", "file": "yes.wav", "aliases": []}
]}
```

WAV — PCM 16 бит, моно, до 30 секунд. При отсутствии подходящей записи используется
синтезатор. Пользовательская папка проверяется первой, встроенная — следом.
Выбор применяется к ПК, браузеру и Android при выборе голоса ПК на телефоне.
При недоступном синтезе браузер сохраняет системную озвучку как резервный вариант.

## Кэш и загрузка

- Одинаковые запросы в одном процессе синтезируются один раз.
- WAV публикуется атомарно, временные имена уникальны и удаляются при ошибке.
- Очистка кэша при обращениях не чаще раза в минуту: срок 7 дней, целевой объём
  256 МиБ. Текущая выдаваемая запись сохраняется.
- Замена модели или WAV меняет ключ дискового и оперативного кэша.
- В памяти остаются не более трёх недавно использованных моделей Piper.
- Встроенные голоса скачиваются общим загрузчиком с докачкой и таймаутами.

Проверки: `python -m unittest discover -s tests -p 'test_tts*.py'`,
`node tests/voice_output_test.js`, `python scripts/check_source.py`.
