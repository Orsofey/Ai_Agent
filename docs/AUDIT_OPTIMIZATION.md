# Аудит и изменения озвучки

База: main, коммит `1f8a09676054a4dbe3b9f05d30804957cf78f9c8`.

## Исправлено

- Воспроизведён и устранён конфликт одинаковых параллельных запросов WAV.
  Внутри процесса синтез выполняется один раз; отдельные процессы используют
  уникальные временные файлы и атомарную публикацию.
- Ограничены дисковый кэш WAV и количество загруженных моделей Piper.
- Ключ кэша учитывает корневую папку, модель, конфигурацию и запись персонажа.
- Убрана отдельная реализация загрузки Piper: используется общий загрузчик.
- Добавлены 58 записей Джарвиса из пользовательского архива и сопоставление реплик.
- Модели `jarvis.onnx` и `friday.onnx` автоматически используются персонажами,
  если пользователь установил соответствующие модели. Самих моделей в исходниках нет.
- Маршруты выдачи WAV вынесены в `src/tts_api.py`; существующая авторизация
  приложения продолжает применяться к ним.
- Браузерный клиент запрашивает голос ПК; отмена останавливает запрос и звук,
  устаревший ответ не воспроизводится. Системная речь остаётся резервной.
- Сборка проверяет локальные импорты и шаблоны до упаковки.

## Что блокирует полноценный запуск

Отсутствуют `src.journal`, `src.chat_tools`, `src.checklist`, `src.skills`,
`src.learning`, `src.user_facts`, `src.share`, `src.calls`, `src.approvals`,
`src.automations`, `src.coach`, `src.updates`, `src.privacy_policy`,
`src.site_groups`, `src.dictation`, `src.coach_popup`, включая необходимые подмодули.
Также отсутствуют `templates/dictation.html` и `templates/coach.html`.

Точный список мест использования выдаёт `python scripts/check_source.py --json`.
Обязательные импорты не заменялись заглушками: это скрыло бы потерю функций.
Нужны полные исходники работающей версии для сопоставления и восстановления.

## Дублирование

Полностью одинаковые изображения имеют одинаковый Git blob SHA:
`android_client/assets/icon.png` и `static/icon.png`, `docs/UI_PREVIEW.png` и
`docs/screenshots/theme-aurora.png`. Git уже хранит каждый такой объект однократно;
удаление путей не ускоряет приложение. Они оставлены для совместимости ресурсов
Flutter, веб-клиента и документации.

`src/whisper_recognizer.py` и `scripts/download_piper.py` уже являются тонкими
обёртками совместимости. Сохранены старые пути импорта и команды запуска.
`license.py`/`licenses.py`, `files.py`/`file_ops.py`/`file_index.py` и
`local_tts_service.py`/`tts_player.py` решают разные задачи.

## Проверки и ограничения

- 23 теста синтеза, кэша, записей, моделей и выделенных HTTP-маршрутов проходят.
- 18 существующих тестов голосового цикла проходят.
- 4 проверки браузерной озвучки в Node проходят.
- Проверка синтаксиса Python и JavaScript проходит.
- Полный API-набор блокируется существующим отсутствием `src.journal`.
- Проверка комплектности ожидаемо сообщает о недостающих исходниках.

Нейросинтез настоящими моделями, аудиоустройство, установщики Windows/macOS,
качество сходства с актёрами и запуск Android в этой среде не проверены.
Для Пятницы не получены записи кинодубляжа; для новых фраз обоих персонажей
не получены отдельные модели актёрских голосов.

После восстановления исходников нужны замеры холодного запуска, памяти и
задержки ответа, затем адресная оптимизация по измерениям.
