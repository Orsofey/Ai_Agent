## Голоса Piper

У каждого голоса своя лицензия датасета. Программа скачивает карточку голоса (MODEL_CARD)
вместе с моделью и показывает её на странице «Лицензии». Перед коммерческим распространением проверьте
карточки голосов irina, denis и amy. Убраны: голос lessac (датасет только для исследований) и Silero TTS (CC BY-NC).

## Важно для коммерческого использования

- piper-tts и eSpeak NG распространяются по GPL-3.0: при распространении программы вместе с ними
  действуют условия GPL (в том числе предоставление исходного кода).
- DuckDuckGo выключен по умолчанию: у сервиса нет открытого API.
- Названия сторонних программ и сервисов обозначают совместимость, а не партнёрство.
