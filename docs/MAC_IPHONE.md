# «Андрей» на macOS и iPhone

## macOS (12 Monterey и новее, Apple Silicon и Intel)

Работает всё то же, что на Windows: имя «Андрей», голосовые команды в любом приложении
(«напиши текст…» в Pages, Word, Telegram), мессенджеры, YouTube, ответы локальной нейросети.

**Установка из исходников**

```bash
./SETUP_MAC.sh        # зависимости, модели речи, голоса, llama.cpp (Metal) и Qwen3 4B — один раз
./START_MAC.command   # запуск (или двойной щелчок в Finder)
```

**Готовое приложение**: `./BUILD_MAC.sh` собирает `dist/Andrey.dmg` со всеми моделями внутри.
Пользователь перетаскивает «Андрей» в «Программы» — интернет не нужен.
Без Apple Developer ID приложение подписывается ad-hoc: первый запуск — правый клик → «Открыть».
Для раздачи без предупреждений: `MAC_SIGN_IDENTITY="Developer ID Application: …" ./BUILD_MAC.sh`
и нотаризация `xcrun notarytool`.

**Разрешения** (Системные настройки → Конфиденциальность и безопасность), один раз:

| Разрешение | Зачем |
|---|---|
| Микрофон | слушать «Андрей, …» |
| Универсальный доступ | печатать текст и нажимать клавиши в других приложениях |
| Мониторинг ввода | глобальная горячая клавиша ⌃⌥Пробел |
| Автоматизация (System Events) | окна: свернуть, развернуть, заблокировать экран |

**Отличия от Windows**

- Сочетания переводятся в привычные для Mac: «Скопируй» → ⌘C, «Отмени» → ⌘Z, «Повтори» → ⇧⌘Z,
  «Покажи рабочий стол» → ⌘F3, «Закрой окно» → ⌘W.
- «Закрой Safari» вежливо завершает приложение (как ⌘Q): несохранённые документы оно спросит само.
- Нейросеть использует видеокарту Apple (Metal) всегда — переключатель «Ускорение видеокартой» не нужен.
- Иконки в строке меню нет (её нельзя совместить с окном pywebview): приложение живёт в Dock.
- Автозапуск — через LaunchAgent `~/Library/LaunchAgents/ru.andrey.assistant.plist`.
- Запасной голос, если голоса Piper не скачаны, — системный `say` (Milena для русского).
- Данные: `~/Library/Application Support/LocalAIAgent`.

## iPhone и iPad

Полноценный «Андрей» на самом iPhone невозможен: iOS не даёт приложениям печатать в другие
приложения и управлять ими, а распознавание речи и нейросеть на 4 ГБ не помещаются в
ограничения фоновой работы iOS. Поэтому iPhone работает как **пульт и голосовой вход** для ПК или Mac.

**1. Приложение на экране «Домой»** (без App Store)

1. На ПК: Настройки → «iPhone и Android» — там QR-код.
2. Наведите камеру iPhone на код — откроется «Андрей», уже подключённый к этому компьютеру.
3. «Поделиться» → «На экран Домой». Появится значок «Андрей», открывается на весь экран.

Команды можно печатать или диктовать кнопкой 🎤 на клавиатуре iPhone (кнопка микрофона в самом
приложении подскажет это: Safari даёт сайтам микрофон только по HTTPS, а в домашней сети его нет).

**2. «Привет, Siri, Андрей»** — голосом, даже с заблокированного iPhone, AirPods или Apple Watch

В приложении «Быстрые команды» создайте команду «Андрей»:

1. «Диктовать текст».
2. «Получить содержимое URL»: `http://IP-компьютера:5000/api/siri` (точный адрес — в настройках),
   метод POST, заголовок `X-Agent-Token` = код подключения, тело JSON: `text` = «Диктованный текст».
3. «Получить значение для ключа» `response` → «Произнести текст».

Скажите «Привет, Siri, Андрей» → «открой ютуб на компьютере», «какая погода завтра».
Команда выполняется на компьютере, ответ читает Siri.

Для доступа не из дома используйте VPN (например, WireGuard или Tailscale): локальный HTTP не шифруется.
