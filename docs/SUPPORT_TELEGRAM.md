# «Ваши предложения» → вам лично в Telegram

Плашка «Ваши предложения» в центре верхней панели (и голосом: «Андрей, предложение: …») отправляет сообщение
на **сервер аккаунтов** (Amvera), а сервер пересылает его вам в Telegram ботом. Кнопка «Написать в Telegram лично»
открывает чат с вами.

> Важно: приём предложений работает **на сервере**. Пересобрать .exe недостаточно — после обновления кода нужно
> загрузить на Amvera новое содержимое папки `server/`.

## Настройка (один раз, 5 минут)

1. Telegram → **@BotFather** → `/newbot` → придумайте имя → скопируйте **токен**.
2. Откройте своего нового бота и нажмите **«Старт»** (`/start`) — со своего аккаунта.
3. Amvera → проект сервера:
   - **Репозиторий/Файлы**: загрузите всё содержимое папки `server/` из последней версии (там есть `support.py`).
   - **Переменные** (токен — в **Секреты**):

     | Имя | Значение |
     |---|---|
     | `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
     | `SUPPORT_TELEGRAM` | ваш ник без @ (для кнопки «Написать лично» и чтобы бот точно нашёл именно ваш чат) |

   - Нажмите **«Пересобрать»/«Перезапустить»**.
4. В приложении: «Ваши предложения» → **«Не доходит? Проверить связь» → «Проверить»**. Должны быть все зелёные галочки.

`TELEGRAM_CHAT_ID` больше задавать не нужно: сервер сам находит ваш чат по `/start`. Его можно указать вручную, если
хотите получать предложения в другой чат.

## Если не работает — «Проверить связь» покажет, где именно

| Что пишет проверка | Что сделать |
|---|---|
| Не задан адрес сервера аккаунтов | Настройки → «Аккаунт» → «Адрес сервера» (или `SERVER_URL` в `src/license_config.py` перед сборкой) |
| Сервер не отвечает | проверьте, что проект на Amvera запущен и адрес правильный (https://…) |
| На сервере старая версия без «Ваших предложений» | загрузите на Amvera заново папку `server/` и дождитесь сборки |
| Не задан TELEGRAM_BOT_TOKEN | добавьте секрет и перезапустите проект |
| Telegram не принял токен бота | скопируйте токен у @BotFather заново (`/mybots` → бот → API Token) |
| Боту ещё никто не написал /start | откройте бота в Telegram и нажмите «Старт», затем «Проверить» ещё раз |
| Сервер не может достучаться до Telegram | хостинг блокирует api.telegram.org — задайте `TELEGRAM_API_URL` (адрес прокси Bot API) |

Служебные страницы (нужна переменная `OWNER_PASSWORD`):
- пробное сообщение: `https://<сервер>/support/test?key=<OWNER_PASSWORD>`;
- все предложения: `https://<сервер>/support/list?key=<OWNER_PASSWORD>`;
- диагностика без пароля и без секретов: `https://<сервер>/api/support/check`.

Без интернета приложение сохраняет предложение и отправит его позже (и при «Проверить связь»).
Защита от спама: не больше 5 сообщений за 10 минут с одного адреса.
