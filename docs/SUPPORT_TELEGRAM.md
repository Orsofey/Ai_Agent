# «Ваши предложения» → вам лично в Telegram

Плашка «Ваши предложения» в центре верхней панели (и голосом: «Андрей, предложение: …») отправляет сообщение
на сервер аккаунтов, а сервер пересылает его вам в Telegram ботом. Кнопка «Написать в Telegram лично»
открывает чат с вами (текст копируется в буфер — пользователь вставляет его Ctrl+V).

## Настройка (один раз, 5 минут)

1. В Telegram напишите **@BotFather** → `/newbot` → имя, например «Андрей — предложения». Скопируйте токен.
2. Напишите своему новому боту `/start` (иначе бот не сможет вам писать).
3. Amvera → ваш проект сервера → **Переменные** (токен — в **Секреты**):

   | Имя | Значение |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | токен от @BotFather (секрет) |
   | `SUPPORT_TELEGRAM` | ваш ник без @ — для кнопки «Написать лично» |
   | `TELEGRAM_CHAT_ID` | ваш chat id (шаг 4) |

4. Перезапустите сервер и откройте `https://<адрес-сервера>/support/chat-id?key=<OWNER_PASSWORD>` —
   там будет ваш `chat_id`. Впишите его в `TELEGRAM_CHAT_ID` и перезапустите ещё раз.

Готово: предложения приходят сообщением «💡 Предложение №…» с текстом, контактом пользователя и версией программы.

- Все предложения хранятся в базе сервера: `https://<адрес-сервера>/support/list?key=<OWNER_PASSWORD>`.
- Без интернета приложение сохраняет предложение и отправит его позже.
- Защита от спама: не больше 5 сообщений за 10 минут с одного адреса.
