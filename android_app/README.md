# Local AI Agent — Android-клиент (Flutter)

Тонкий WebView-клиент, который подключается к агенту на ПК по локальной сети.
Все команды выполняет ПК; телефон — это пульт с микрофоном.

## Требования

- Flutter SDK 3.16+ → https://docs.flutter.dev/get-started/install/windows
- Android Studio (для Android SDK и эмулятора)
- После установки: `flutter doctor` должен быть без ошибок

## Сборка APK

```bat
cd android_app
flutter pub get
flutter build apk --release
```

Готовый файл: `android_app\build\app\outputs\flutter-apk\app-release.apk`

Установить на телефон: перекиньте APK и откройте его (разрешите установку
из неизвестных источников). Либо подключите телефон по USB и:

```bat
flutter install
```

## Как это работает

1. Запустите агент на ПК (`run.bat` или установщик).
2. В консоли ПК появится адрес вида `http://192.168.1.5:5000`.
3. Откройте приложение на телефоне, введите этот адрес (или он подхватится
   автоматически, если ПК в той же сети).
4. Нажмите «Подключиться» — откроется интерфейс агента.
5. Пользуйтесь голосом/текстом — команды уходят на ПК и выполняются там.

## Первый запуск: обнаружение ПК

Приложение пробует типичные адреса (`192.168.x.x:5000`) через `/health`.
Если не нашло — введите адрес вручную. Он сохранится.
